Personal-use integration

Sol Backups

Sol Backups is a personal Google Drive integration for storing and restoring encrypted backups of the operator's own Sol application data.

How it works

restic encrypts backup snapshots before upload. rclone transfers the encrypted repository to the operator's Google Drive using an explicitly authorized Google OAuth connection. Restoration requires the repository password.

Google Drive access

The integration requests only https://www.googleapis.com/auth/drive.file. This allows access to files created by this integration or explicitly made available to it, not unrestricted access to the account's entire Drive. The permission includes reading, creating, modifying and deleting those accessible files.

The integration is being configured for the operator's personal use. This site is documentation, not a public backup service or a sign-in portal. Do not enter passwords, tokens or backup contents on this site.

Privacy and operator
